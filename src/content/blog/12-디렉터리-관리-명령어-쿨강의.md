디렉터리 관리 명령어.
맨날 cd랑 ls 만 잔뜩 써왔는데, 조금 더 넓혀 보고자 빠르고 간단하게 정리해보려 한다.

### `pwd` : 지금 어디에 있나
- 현재 작업 중인 디렉터리의 위치(경로)를 출력한다.

### `cd` 디렉터리 이동
- `~`는 현재 사용자의 홈 디렉터리로 간다.
	- [틸다] 라고 읽음.

### `mkdir`
- make directory
- 새로운 디렉터리를 만든다.
- `-m` 옵션으로 [권한](/blog/8-리눅스의-권한과-그룹/)도 같이 설정 가능

### `rmdir`
- 디렉터리 삭제
	- 내부에 파일 존재하는 경우 삭제 안됨. 
	- `rm -rf` 써야지 내부 재귀적으로 파일까지 전체 삭제됨

### 진리의 `ls`
- `-a`: 히든 파일 포함하여 노출
- `-l`: 자세한 정보까지 (사이즈 등)
- `-d`: 디렉터리 정보 출력
- `-r`: 알파벳 역순
- `-R` 하위와 그 안에 있는 파일 표시

### `cp` = copy
- 디렉터리나 파일을 복사한다.
- `-b`: 이미 존재할 경우 대비 백업 파일을 만듦

### `rm` 
- 파일 또는 디렉터리 삭제
- 질의를 원할 경우 `-i`
- 내부까지 삭제는 `-r`

### `mv` 파일 이동 또는 이름 변경
- `-v` 파일 옮겨지는 과정 자세히 표시함
- 이것도 백업 파일 생성(`-b`), 질의없는 강제 처리(`-f`) 있음

### `touch`
- 파일 크기가 0바이트인 빈 파일을 생성
- 서버 현재 시간으로 [타임 스탬프](/blog/10-inode별-세개/)를 변경한다.
	- 접근 시간(atime): 시스템 호출을 사용해 파일을 읽은 시간
	- 수정 시간(mtime): 파일 **내용**이 변경된 시간
	- 변경 시간(ctime): 파일 내용+메타데이터가 수정되었을 때 기록되는 시간
		- 수정 불가능

### `file`
- 파일 종류/속성 값을 나타냄
- `-b`: 파일명은 출력하지 않고 파일 유형만 표시
- `-f`: 파일 목록에서 지정한 파일들에 대해서만 명령을 실행
- `-z`: 압축된 파일 내용 출력
- `-i`: MIME 타입 문자로 출력

### `find`
- 현재 디렉터리부터 하위 디렉터리까지 주어진 조건의 파일을 찾아 해당 경로를 표시한다.
```bash
find [경로] [옵션] [정규표현식] [파일명]
```
- `-name`: 이름 기준
- `-user`: user의 파일이나 디렉터리 검색
- `-perm`: 지정된 권한의 파일 검색
- `-type`: 파일 유형에 따라 파일 검색
- `-atime n`: n일 이전에 접근한 파일 검색
- `-exec`: 검색된 파일에 수행할 명령어를 지정

### `locate 파일명`
- 파일의 위치를 찾는 명령어


### `cat`
- 파일 내용 출력
- `-n`: 각 문장 앞에 번호 표시 (비어있는 행 포함)
- `-b`: 각 문장 앞에 번호 표시 (비어있는 행 제외)

### `head`
- 파일의 앞부분을 지정한 만큼 출력
- `-c`: 숫자 바이트 만큼의 문자 출력
- `-숫자`, `-n 숫자`: 원하는 줄 수만큼 출력 (기본 10줄)

### `tail`
- 마지막 행 기준으로 지정한 행까지 파일 내용 출력
- `-f`: **새롭게 추가되는 파일 내용 실시간 출력**
	- 로그 볼 때 진짜 많이 씀..


### `more`
- 파일을 화면 단위로 끊어서 출력
- 위에서 아래 방향으로 출력된다.
- 지나간 내용 다시 못 봄..

### `less`
- 텍스트 파일을 한 번에 한 화면씩 나타내는 명령어
- 커서를 파일의 상하좌우로 이동 가능
	- more는 스페이스바로 다음 페이지 갈 수 있음..

### `grep` 별표 다섯 개
- 특정한 패턴 또는 정규 표현식으로 나타낸 단어를 찾는 명령어
- `-r`: 디렉터리 내의 모든 파일을 검색
- `-E`: 패턴을 정규 표현식으로 확장
	- escape 안해도 되는 장점이 있음
- `-i`: 대소문자 ignore
- `-v`: 검색할 문자열이 포함되지 않은 줄만 출력
- `-n`: 라인 수 출력
- `-l`: 문자열이 포함된 파일명 출력


```bash
grep adm /etc/passwd

= /etc/passwd 파일에서 문자 adm을 포함하는 내용을 출력
```

```bash
grep -l 'rm' *

= 현재 디렉터리에서 'rm'이라는 문자열이 들어간 파일 이름 검색
```

### `wc`
- 파일 라인 수, 단어 수, 문자(바이트) 수 출력

### `sort`
- 명령어 결과나 문서 내용을 정렬하는 명령어

### `cut`
- 파일에서 특정 필드를 추출해 낸다.
- 구분자 사용 가능 `-d`

### `split`
- 하나의 파일을 여러 개의 작은 파일로 분리할 때 사용
- 라인 수 또는 용량 단위로 분할 가능
- 디스켓에 파일 나눠서 복사/백업 할때 유용함

### `diff` 
- 두 개의 파일을 행 단위로 비교(가로 방향)하여 다른 부분을 출력하는 명령어
- `-s`: 두 파일이 같은지 확인

### `cmp`
- 두 개의 파일을 바이트 단위로 비교하여 출력하는 명령어
- `comm`: 두 개의 파일을 줄 단위로 비교(위 아래 방향)

# 리다이렉션
> 표준 입력과 표준 출력의 방향을 재지정

- 모니터로의 출력이 파일로의 출력으로 재지정된다.
- 표준 입력장치: 키보드
- 표준 출력장치: 모니터
- 표준 에러장치: 모니터
- `>`: 명령을 화면이 아닌 프린터나 파일에 출력
- `>>`: 지정된 파일에 결과를 추가
- `<`: 키보드가 아닌 지정된 파일에서 입력 내용을 읽어옴
- `>&`: 출력 파일 디스크립터를 다른 디스크립터로 복제 (예: `2>&1`은 표준에러를 표준출력으로 합침)
- `<&`: 입력 파일 디스크립터를 다른 디스크립터로 복제 (예: `0<&3`은 표준입력을 3번 디스크립터에서 읽어오도록 바꿈)

### 파이프 `|`
> 현재 명령의 표준 출력을 다음 명령의 표준 입력으로 사용하는 것

```bash
명령어1 | 명령어2 | 명령어3

= 명령어1의 결과가 명령어 2의 입력이 되고, 명령어2의 출력이 명령어3의 입력이 됨.
```
- 더 이상 처리할 명령어가 없으면 표준 출력 장치(모니터)로 출력된다.
