리눅스 운영체제는 설치를 위한 소스/인터페이스/목적에 따라 분류할 수 있다.


# 설치 소스에 따른 분류
> 어떤 소스를 통해 설치하는가에 따른 분류

### 로컬 설치
- 물리 매체에 담긴 이미지로 설치
	- CD/DVD, USB
### 네트워크 설치
- 서버에 설치 이미지를 두고 원격으로 설치
	- NFS, FTP, HTTP/HTTPS 서버
### PXE 설치
- 네트워크 부팅(PXE)으로 여러 대의 PC에 동시에 무인 설치
- 주로 kickstart 등과 결합하여 설치한다.
	- kickstart: 설치 응답을 자동화하는 스크립트

---

# 인터페이스에 따른 분류
> 어떤 모드로 os를 다룰지에 대한 분류

### 그래픽 모드 GUI
- 마우스로 조작하는 설치 화면이다. 일반적으로 사용자들이 그래픽을 보면서 마우스로 조작하는 모드.
### 텍스트 모드 CLI
- 주로 서버 설치 시에 사용한다.
### VNC 모드
- 원격 서버 설치 시 그래픽 화면을 VNC 뷰어로 원격 접속해 진행한다.

---

# 파티션 구성 방식에 따른 분류
> 자동 파티셔닝, 수동 파티셔닝으로 나눌 수 있다.

### 자동 파티셔닝
설치 프로그램이 권장 파티션을 자동으로 생성한다.
- 권장 파티션: `/`, `/boot`, `swap` 등

### 수동 파티셔닝
사용자가 직접 파티션 크기, 마운트 포인트, 파일 시스템 종류를 지정한다.
- 설치 마법사에서 수동 파티셔닝할 수 있다.

# 설치 유형

리눅스 설치 유형은 [배포판](/blog/1-리눅스란/)마다 다르긴 하지만 패키지에 따라 데스크톱형/서버형/사용자 정의형으로 구분한다. 각 종류마다 기본으로 설치하는 패키지, 지원하는 인터페이스 등이 달라진다.

### Minimal
- 필수 패키지만 설치
- GUI를 포함하지 않는다.

### 데스크톱
- 개인용 컴퓨터(PC)에 적합
- 하드디스크의 모든 리눅스 파티션을 삭제하고 데스크톱 환경에 적합한 환경으로 설치
	- 하드디스크를 자동 재구성하므로, 기존에 있던 데이터는 사라진다.
- 문서 작성, 멀티미디어, 그래픽 도구 관련 프로그램 설치
- minimal 데스크톱도 있음
	- 문서 작성 등은 설치 되지 않음

### 서버
- 하드디스크의 모든 파티션을 삭제하고 서버 운영에 적합한 패키지를 설치
	- basic: 리눅스 서버 필수 기본 패키지 설치
		- 시스템 관리 기본 패키지(기본 명령어, 프로세스 관리 등)
		- 네트워크 관련 패키지(원격접속, ip, 방화벽 등)
		- 패키지 관리 도구
		- 압축, 아카이브 도구(tar, gzip, bzip, xz 등)
		- 텍스트 편집기(vi, vim, nano)
		- 개발/컴파일 도구(gcc, make)
		- selinux-policy 등
	- database: 데이터베이스 서버 관련 패키지 설치
	- web: 웹 서버 관련 패키지 설치(apache2, httpd, nginx 등)
	- dns: dns 서버 관련 패키지 설치(bind9, bind 등)
	- file: 파일 서버 관련 패키지 설치
	- mail: 메일 서버 관련 패키지 설치
- 서버 운영에 최적화된 자원 사용을 위해 GUI를 배제한다.

### 랩탑
- 노트북에 적합한 패키지 설치

### 가상 호스트
- 가상화 시스템 운영을 위한 패키지 설치
- 하이퍼바이저 KVM이나 Xen 설치
	- 하이퍼바이저
		- 하나의 물리 하드웨어(서버)위에 여러 개의 vm을 생성/실행/관리하는 소프트웨어
	-  KVM
		- Kernel-based Virtual Machine
		- 리눅스 커널에 내장된 하이퍼바이저
		- type-1(하드웨어 바로 위에서 돌아가는 구조)처럼 동작
		- 하지만 리눅스 커널 위에서 돌아가는 구조로, type-1.5라고도 부름
		- 완전 가상화가 기본 모드
			- 게스트 os가 자신이 가상화된 환경 내 실행 중임을 인지하지 못한다. 하이퍼바이저가 하드웨어를 완벽하게 흉내 내어 그 위에 게스트 os는 그대로 설치된다.
	- Xen
		- 오픈소스
		- 반가상화(PV)와 완전가상화(HVM) 모두 지원
			- 반가상화: 게스트 os가 자신이 가상화된 환경 내 실행 중임을 인지하고, 커널을 하이퍼바이저 전용으로 수정하여 하이퍼콜을 통해 요청한다.
			- 완전가상화: 게스트 os가 자신이 가상화된 환경 내 실행 중임을 인지하지 못하며, 커널 수정 없이 그대로 설치된다.

### Software Development Workstation
- sw 설치 시 필요한 도구 포함된 패키지 설치
- 소스 컴파일 도구를 기본적으로 포함
