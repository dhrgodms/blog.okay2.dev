# 1. 응애 리눅스 태어났어요
- 리눅스는 UNIX 기반 운영체제다.
- UNIX -> GNU 프로젝트 -> Linux (리누스 토르발스)탄생 흐름
### UNIX란? 
> C언어로 작성된 운영체제로, 하드웨어와의 이식성이 좋다.
- 벨 연구소에서 켄 톰슨이랑 데니스 리치가 만듦
- unix의 시작은 AT&T가 독점 규제법으로 통신 외에는 사업을 할 수 없었기에 적은 돈을 받고 배포하는 자유 SW 성격이 강했다. 이때 대학을 중심으로 자유롭게 공유되었다.
- 1980년대, AT&T가 통신 독점 규제에 대해서 자유로워지면서 UNIX에 더 높은 가격을 매겨 정식 판매하기 시작했다.
	- 폐쇄적이고, 유료 소프트웨어였던 것..!

### GNU
- GNU 프로젝트는 리처드 스톨만이 시작한 **자유 소프트웨어**(지금의 오픈 소스의 근간)를 지향하는 프로젝트 였다.
- GNU 프로젝트의 : "자유 소프트웨어로 UNIX와 호환되는 OS를 만들어야겠다" 
	- (근데 커널만 빼고 만듦)
	- 이 커널을 리누스 토르발스가 만들었다!
	- 그래서 나오게 된게 Linux

> Linux = GNU프로젝트 + 커널(리눅스 토르발스)

# 2. 리눅스의 특징
- 오픈 소스다.
	- 당연함. GNU 프로젝트로부터 왔기 때문이다.
- GPL 라이선스를 적용한다. (copyleft라고 부른다. 이유: copyright 반대라서.)
	- General Public License
	- **자유롭게 사용/수정/배포할 수 있으나, 수정한 결과물도 GPL로 공개해야 한다.**
	- 자유 소프트웨어일 때 주로 사용하는 라이선스!
- 다중 사용자, 다중 작업(멀티 태스킹)
	- 여러 사용자가 동시 접속 가능
	- 여러 프로세스를 동시에 실행할 수 있다. (멀티 스레드랑은 또 다르다)
- 하드웨어 이식성 굿
	- c언어 기반인 unix를 뿌리로 한다.
	- 그러나 unix보다는 하드웨어에 덜 종속적인 뛰어난 이식성을 가진다.
- 계층적 파일 시스템
	- 트리 구조의 디렉터리 체계를 가진다.
	- `/`가 최상위 루트
- 안정성 굿
	- 오랜 시간 끄지 않고 두어도 안정적으로 돌아가기 때문에 서버용으로 사용하기 좋다.
- 네트워크 지원 굿
	- tcp/ip 기반 설계 쏘굿

# 3. 간단 리눅스 구조
```
┌─────────────────────────┐
│   응용 프로그램 (User)     │
├─────────────────────────┤
│   쉘 (Shell)             │  ← 사용자와 커널 사이 인터페이스
├─────────────────────────┤
│   커널 (Kernel)          │  ← 하드웨어 직접 제어
├─────────────────────────┤
│   하드웨어                │
└─────────────────────────┘
```

- 커널: 가장 중요.
	- 프로세스 관리, 메모리 관리, 파일 시스템 관리, 장치 관리를 담당한다.
	- 커널이 s/w와 h/w 사이에서 자원을 분배/관리/제어한다.
- 쉘: 명령어 해석기
	- 사용자 명령을 해석해서 커널에 전달한다.
	- 종류 다양함
		- bash, csh, ksh 등

# 4. 리눅스의 다양한 배포판 계열
같은 리눅스더라도 다 같은 리눅스가 아니다. 배포판 별로 종류가 상당히 많다.
- 배포판이 달라지는 이유
	- **커널은 동일한 linux 커널**(`kernel.org`)을 사용한다.
	- 커널에 **주변 요소를 다양하게 덧붙이면서** 배포판이 달라지게 되는 것.
		- 주변 요소 예시: sw 패키지 도구, OS의 목적, 릴리즈 정책, 유지보수 지원, 셸 등

계열은 크게 세 가지로 나눌 수 있다.
1. Debian
	- 패키지: `.deb`, 도구: apt
	- Debian, Ubuntu, Mint ..
2. Red Hat
	- 패키지: `.rpm`, 도구: yum/dnf
	- RHEL, CentOS, Fedora, Rocky Linux
3. Slackware
	- Slackware, SUSE

# 새로 알게 된 것
- 배포판이 커널을 다 동일한 것을 사용한다는 것을 처음 알게 되었다.
- linux가 오픈 소스의 성격을 가지고 더 다채로워진 것이 AT&T의 독점 사업과 관련된 탄생 배경에 있었다는 걸 알게 되었고, 자유 소프트웨어 철학이 현재의 컴퓨터 기반이 되었음을 다시 한번 느낄 수 있었다.
