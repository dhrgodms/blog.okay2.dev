# 1. FHS란
> 루트(`/`)라는 최상위 디렉토리 아래 트리 구조로 연결된 계층형 디렉토리 시스템.
> 각 디렉토리가 어떤 역할을 하는지 표준으로 정해둔 것이다.

- Filesystem Hierarchy Standard
- 윈도우는 드라이브 개념이 있다. (`C:\`, `D:\`)
```
/ (최상위 디렉토리)
├── bin, sbin
├── etc
├── home
├── root
├── var
├── usr
├── lib
├── dev
├── proc
├── tmp
├── boot
├── mnt, media
└── opt
```


# 2. 핵심 디렉토리 별 역할 정리
## 2.1. 실행 파일 관련
- `/bin`
	- **일반 사용자용 필수** 실행 명령어를 담는 디렉토리
	- 예) ls, cp, cat 등
- `/sbin`
	- **시스템 관리용** 실행 명령어
	- 주로 루트 권한이 필요하다.
	- 예) fdisk, reboot 등
- `/usr/bin`, `/usr/sbin`
	- 필수는 아닌 추가 설치된 프로그램들

> [!note] 최근 배포판은 `/bin`, `/sbin`이 `/usr/bin`, `/usr/sbin`으로 심볼릭 링크된 경우가 많다 (`ls -l /bin` 으로 확인 가능)


## 2.2. 설정 & 개인 공간 (홈 디렉토리)
- `/etc`
	- 시스템 설정 파일 모음
	- 예) passwd, fstab, hosts 등
- `/home`
	- 일반 사용자들의 개인 홈 디렉토리
	- `/home/사용자명`
- `/root`
	- root 관리자 전용 홈 디렉토리
	- `/home`과는 별개다.

## 2.3. 가변 데이터 & 임시 공간
- `/var`
	- 계속 크기가 변하는 데이터
	- 로그, 메일, 캐시, 스풀 등
	- 예) `/var/log`
- `/tmp`
	- 임시 파일 저장
	- 재부팅 시 삭제될 수 있음
	- **누구나 쓸 수 있는 공간**!!

## 2.4. 하드웨어 & 커널 관련 (가상 파일시스템)
- `/dev`
	- 장치 파일
	- `/dev/vda`, `/dev/sda` 등
- `/proc`
	- **커널/프로세스 정보**를 파일처럼 보여주는 가상 디렉토리
	- 실제 디스크에는 저장되지 않는다. 사용자에게 파일이라는 인터페이스 형식으로 바로바로 만들어서 보여주는 것이다.
	- 예) cpu/메모리 정보 확인, 현재 실행 중인 프로세스 목록, 상태, 현재 마운트된 파일 시스템 목록 등 확인 가능
- `/sys`
	- **커널의 디바이스/드라이버 정보**를 보여주는 가상 디렉토리
	- 예) 블록 장치(디스크, 파티션) 목록, 디스크의 상세 정보, 네트워크 인터페이스 정보 등 확인 가능


## 미니 실습
```
ls /sys/block
```

![](../../assets/blog/4.-파일-시스템/4.%20파일%20시스템-1786952782178.png)

이 시스템이 인식하는 모든 종류의 블록 장치 드라이버들 목록을 볼 수 있다.
- 실제로 사용 중인 것도 있고, 커널이 만들어둔 빈 슬롯도 포함되어 있다.

### 간단 살펴보기
- vda, vdb
	- docker ubuntu의 가상 디스크
- nbd0~15
	- 네트워크 블록 장치
	- **네트워크 너머 저장 장치를 로컬 디스크처럼** 다루는 커널 기능
	- 현재 사용 중인지(연결되어있는지=bind)는 `lsblk` 결과에 있는 SIZE를 보면 알 수 있다.
	- [2. 파티셔닝](/blog/2-파티셔닝/)에서 다룬 nbd와 동일한 개념이다.
- ram0~15
	- 램 디스크
	- RAM 일부를 마치 디스크처럼 사용할 수 있게 해주는 커널 기능
	- 속도가 빠르지만 휘발성
	- 부팅 초기 단계에 임시로 쓰이거나, 임시 캐시 공간이 필요할 때 사용된다.
	- 커널이 미리 슬롯 만들어두는 것임. 지금 사용 안할 확률 높다.
- loop0~7
	- 루프 장치
	- 파일 하나를 마치 디스크 장치처럼 다룰 수 있게 해주는 기능
		- `.iso`, `.img` 파일을 실제 디스크처럼 마운트해서 그 안의 내용을 볼 수 있게 한다.
		- **컨테이너 환경에서 컨테이너 이미지 레이어 자체를 loop device로 다루는 경우가 흔하다.**

## 2.5. 부팅 & 라이브러리
- `/boot`
	- 커널 이미지(vmlinuz), initramfs, GRUB 설정 등 부팅에 필요한 파일들
- `/lib`, `/usr/lib`
	- 커널 모듈, 공유 라이브러리(.so 파일)
	- python, apt, systemd, usrmerge 등

## 2.6. 외부 저장장치 연결
- `/mnt`
	- 관리자가 임시로 파일 시스템을 수동 마운트할 때 쓰는 공간
- `/media`
	- USB 등 이동식 장치가 자동으로 마운트되는 위치

## 2.7. 기타
- `/opt`
	- 배포판 기본 패키지가 아니고 별도로 설치한 소프트웨어
